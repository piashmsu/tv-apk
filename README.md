## 🏗️ How It's Built

```
🟣 Kotlin 1.9.24          — Language

🟣 Navigation Compose     — Screen Routing

🟣 DataStore Preferences  — Settings Storage
🟣 OkHttp 4.12            — Networking
🟣 Coil 2.6               — Image Loading
🟣 WorkManager            — Background Tasks
🟣 Coroutines + Flow      — Async Data
```

tv-apk/

│   ├── 📦 data/
│   │   ├── Models.kt              ← Channel, Movie, EPG models
│   │   ├── ChannelRepository.kt   ← M3U loader + probe engine
│   │   ├── MovieRepository.kt     ← JSON catalog loader
│   │   ├── EpgRepository.kt       ← XMLTV EPG engine
│   │   ├── M3UParser.kt           ← M3U/M3U8 parser
│   │   ├── EpgParser.kt           ← XMLTV parser
│   │   ├── AppPrefs.kt            ← DataStore prefs + seed
│   │   └── AppContainer.kt        ← DI container
│   ├── 🎨 ui/
│   │   ├── TvApkRoot.kt           ← Navigation + Bottom Bar
│   │   ├── AppViewModels.kt       ← Shared ViewModel
│   │   ├── theme/                 ← Material 3 "Vibe" theme
│   │   ├── components/            ← ChannelTile, MovieCard, Chips
│   │   └── screens/
│   │       ├── HomeScreen.kt      ← Hero, recents, live channels
│   │       ├── LiveTvScreen.kt    ← Channel list + probe UI
│   │       ├── EpgTimelineScreen.kt ← Grid TV guide
│   │       ├── MoviesScreen.kt    ← Genre-grid movies
│   │       ├── SearchScreen.kt    ← Global search
│   │       ├── SettingsScreen.kt  ← Playlists, debug logs
│   │       └── PlayerScreen.kt    ← PiP, record, full player
│   ├── ▶️ player/
│   │   └── PlayerFactory.kt       ← ExoPlayer builder
│   ├── 🔴 record/
│   │   └── RecordingService.kt    ← Stream recorder
│   └── ⏰ work/
│       └── PlaylistRefreshWorker.kt ← Auto-refresh scheduler
